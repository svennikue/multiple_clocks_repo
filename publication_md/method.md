# Methods — ROI-based single-unit RSA for DSR and state models

This analysis used [scripts/RSA_DSR_ROIs_simple.py](/Users/xpsy1114/Documents/projects/multiple_clocks/multiple_clocks_repo/scripts/RSA_DSR_ROIs_simple.py) to quantify representational similarity structure in human single-unit recordings during the 3 x 3 grid sequential-reward task. The script operated on trial-warped firing-rate traces from `data/ephys_humans/derivatives`, using eight task configurations (`3-7-9-5`, `8-2-6-7`, `1-9-5-8`, `4-8-1-3`, `6-4-2-9`, `9-1-3-4`, `7-3-4-2`, `2-5-7-6`). Each configuration contributed 12 condition bins, yielding 96 condition-level population states per representational dissimilarity matrix (RDM). ROI labels were taken from the `alt_final_roi` column of `neurons_with_final_roi_labels.csv`. Nine ROI labels were targeted (`ACC`, `EC`, `Parahippocampal`, `HC_anterior`, `HC_mid`, `medialOFC`, `medial_CC`, `PCC`, `Visual`), but only seven entered the final summaries because `medial_CC` and `Visual` contained no labelled neurons in the single-unit table. The analysed sample comprised 536 neurons across 28 subjects: ACC, n = 68; EC, n = 11; Parahippocampal, n = 46; HC_anterior, n = 179; HC_mid, n = 88; medialOFC, n = 90; PCC, n = 54.

For each ROI, population vectors were assembled separately for each task half (run 1 and run 2) and each configuration. The primary cross-run RSA metric (`split_halves`) was computed from the correlation structure between run-1 and run-2 population matrices, so its RDM contained both within-configuration, across-run cells and between-configuration cells. A secondary run-averaged metric (`between_tasks`) averaged repeated trials within configuration before RDM construction and then retained only off-block, between-configuration cells, excluding the within-configuration block diagonal to avoid trivial autocorrelation. Raw and z-scored versions of each test were analysed, giving four test variants: `split_halves`, `split_halves_z`, `between_tasks`, and `between_tasks_z`. In the z-scored variants, each neuron's activity vector was standardised across bins before the RDM was computed.

Model RDMs were generated from the task structure and behavioural trajectories. The script evaluated three DSR-family models (`dsr_fmri`, `dsr_fmri_fut`, `dsr_fmri_informed`) together with control RDMs for `state`, `midnight`, `bttn_curr`, `bttn_next`, `location`, `l2_norm`, `phase`, `repeat_counter`, `uncover`, `state_phase`, and, in the final state run, `reward_path`. `dsr_fmri` was the full action-plan model, `dsr_fmri_fut` removed lag 0, and `dsr_fmri_informed` retained the pre-registered lag-1/lag-2 subset motivated by an independent fMRI result. Multi-regressor RSA was implemented by stacking the relevant model RDM vectors and fitting them jointly to the data RDM, yielding a regression coefficient for each sub-model within a control set.

Two run families are relevant here. First, the DSR comparison run (`2026-06-22_16-17-15-DSR`) used 1,000 circular-shift permutations, removed phase structure at the single-cell level with cosine residualisation (`phase_residualise = "cosine"`), and compared three matched control stacks that differed only in the DSR regressor: `ctrl_dsrFULL` (`dsr_fmri`), `ctrl_dsrFUT` (`dsr_fmri_fut`), and `fdr_dsrInformed` (`dsr_fmri_informed`). All three included the same non-DSR controls (`bttn_curr`, `bttn_next`, `location`, `l2_norm`, `state`). Second, the state companion run (`2026-06-26_11-30-30-final-State`) used 500 permutations, did not residualise phase, and quantified the `state` regressor within three related combinations: `ctrl_dsrFULL`, `ctrl_dsrFULL_phase`, and `ctrl_dsrFULL_state-phase`. These included `dsr_fmri`, `location`, `l2_norm`, `reward_path`, and `repeat_counter` as shared controls, with `phase` or `state_phase` added in the latter two stacks.

Phase residualisation was implemented at the raw single-cell time-series level, before downsampling or RDM construction. In the DSR run, each neuron's 360-bin firing-rate trace was passed through `_residualise_phase` with a cosine basis, and the phase-predictable component of the firing pattern was subtracted from the data while preserving the neuron's mean firing rate. This operation was applied to the neural data only, not to the model RDMs. Conceptually, the goal was to remove within-state phase tuning from the population vectors so that any surviving DSR effect reflected structure beyond simple phase differences. The script notes that this data-level residualisation is more conservative than adding a categorical phase RDM as a control regressor, because it removes only the component of each cell's response that is predicted by a smooth phase basis rather than forcing all phase-structured variance out at the RDM-regression stage. Other basis options (`cosine_2h`, `categorical`) exist in the script, but the reported DSR analysis used the default single-harmonic cosine basis. Because phase variance was removed directly from the data in that run, the script also kept `phase_mask_mode = "full"` and did not interpret within-phase versus across-phase RDM masks for the residualised dataset.

Significance was assessed with circular-shift permutation tests applied independently within each ROI. For each permutation, each neuron's 360-bin firing-rate trace was circularly shifted within trial, preserving autocorrelation and marginal firing statistics while disrupting alignment to task structure. The empirical beta for a given ROI and sub-model was compared with the permutation null as `p_perm = (#{null >= empirical} + 1) / (N_perm + 1)`. Parametric t statistics from the regression were retained as descriptive effect-size summaries, but inference was based on the permutation p values. For the DSR run, the confirmatory family was pre-specified as the `dsr_fmri_informed` effect in the `fdr_dsrInformed` model under `split_halves_z`, corrected across ROIs by Benjamini-Hochberg false discovery rate (FDR). For the state companion panel, the figure-relevant analysis used `split_halves_z`, `sub_model = state`, `combo = ctrl_dsrFULL`; because that sub-model was not flagged in the saved CSV as part of the confirmatory family, BH-FDR across the seven analysed ROIs was recomputed post hoc from the saved permutation p values when preparing the figure text. In the script, `split_halves_z` denotes the z-scored cross-run RDM that includes both within-configuration-across-run and between-configuration cells, whereas `between_tasks_z` is the stricter off-block-only across-task variant.

Run-balance diagnostics were written for each analysis and showed no flagged subjects (`flag_unbalanced = False`, `flag_systematic = False` for all 28 subjects). All numerical outputs reported below derive from the saved `results_summary_combos.csv` tables in the corresponding run directories.
