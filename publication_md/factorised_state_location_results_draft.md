# Results draft - factorised representations of physical and abstract location

Planning in this task requires two separable forms of location information. Participants must know where they are in the physical 3 x 3 maze, but they must also know where they are in the abstract sequence of the task: whether the current segment corresponds to state A, B, C or D. We therefore asked whether human medial temporal and prefrontal recordings contained a factorised code, with hippocampal populations representing the current physical location and entorhinal-prefrontal populations carrying the abstract state of the task. We tested this with single-neuron recordings from 955 task-active neurons across seven regions and with fMRI in the same task.

We first tested physical location coding in the single-neuron population geometry. In a representational similarity analysis (RSA), the location model captured similarity between task bins with the same current screen location. This model was strongest in medial temporal regions. In the primary cross-run, z-scored RSA (`split_halves_z`), physical location survived permutation testing and Benjamini-Hochberg FDR correction across the seven regions in parahippocampal cortex (beta = 0.0643, t = 4.35, P_perm = 0.000999, q = 0.00699; n = 46 neurons), anterior hippocampus (beta = 0.0434, t = 2.93, P_perm = 0.001998, q = 0.00699; n = 179) and mid-hippocampus (beta = 0.0399, t = 2.69, P_perm = 0.00799, q = 0.0186; n = 88). The same regional pattern was present when only between-task configuration cells were used (`between_tasks_z`): parahippocampal cortex (beta = 0.0530, P_perm = 0.000999, q = 0.00699), anterior hippocampus (beta = 0.0461, P_perm = 0.002997, q = 0.0105) and mid-hippocampus (beta = 0.0441, P_perm = 0.00899, q = 0.0210) again survived correction. By contrast, ACC, medial OFC, PCC and EC did not survive correction in the single-model location RSA. In the multi-regressor RSA used for the DSR analysis, which included current and next button presses, abstract state and the DSR model in the same design matrix, the location term remained nominally positive in mid-hippocampus (beta = 0.0339, t = 1.85, P_perm = 0.040; n = 88) and parahippocampal cortex (beta = 0.0353, t = 1.92, P_perm = 0.039; n = 46), with a trend in anterior hippocampus (beta = 0.0306, t = 1.67, P_perm = 0.058; n = 179). These controlled effects should be interpreted as supportive rather than independently corrected, but they show that the hippocampal location signal is not explained simply by the button-press, state or DSR regressors.

We next asked whether spatial tuning generalized across different task contexts and whether its temporal lag differed by region. This analysis estimated, for each neuron, how well its spatial rate map in one set of task configurations predicted firing in held-out configurations at each angular lag around the path. The current run used phase-residualised firing rates, paired task configurations and pre-specified lags; the final permutation-corrected family statistics are still running and should replace the provisional parametric values below. In the planned tests, ACC was selective for near-future spatial locations rather than the current one: the average of the +30 and +60 deg lags was positive (mean r = 0.0308, t(158) = 2.67, one-sided P = 0.00420, FDR q = 0.026), and these target lags were larger than the remaining lags (t(158) = 2.82, one-sided P = 0.00270, q = 0.00809). Anterior hippocampus showed a positive current-location effect at 0 deg (mean r = 0.0207, t(295) = 2.30, one-sided P = 0.0112, q = 0.026). Mid-hippocampus showed a positive planned 0/330 deg effect (mean r = 0.0249, t(179) = 2.35, one-sided P = 0.00992, q = 0.026), and this target pair was larger than the remaining lags (t(179) = 2.09, one-sided P = 0.0192, q = 0.0288). Thus, the hippocampal signal was anchored to the current or just-previous physical location, whereas ACC was biased toward near-future locations.

We then tested the complementary representation: abstract location in the task sequence. A cross-validated single-neuron encoding model decomposed state coding into a main state component and a state-by-phase component, and classified a neuron as sustained only if its preferred-state contrast remained positive in every phase of held-out task configurations. Sustained state cells were present above the 5% chance rate in all seven regions, but the largest fraction was in EC (9 of 28 cells, 32.1%, binomial P = 5.65 x 10^-6). Sustained cells were also found in ACC (39 of 159, 24.5%, P = 9.89 x 10^-17), medial OFC (34 of 167, 20.4%, P = 2.71 x 10^-12), parahippocampal cortex (12 of 61, 19.7%, P = 4.28 x 10^-5), mid-hippocampus (32 of 180, 17.8%, P = 4.58 x 10^-10), anterior hippocampus (51 of 296, 17.2%, P = 1.48 x 10^-14) and PCC (8 of 64, 12.5%, P = 0.0142). The sustained fraction did not differ significantly across regions in an omnibus chi-squared test (P = 0.183), and the planned EC-versus-rest contrast was suggestive but not significant (one-sided Fisher exact P = 0.073). Therefore, the strongest supported conclusion is that sustained state coding is widespread, with EC numerically highest but not statistically separable from all other regions by cell count alone.

The regions differed more clearly in how much their apparent state coding depended on within-state phase. The fraction of phase-modulated state cells was heterogeneous across regions (omnibus chi-squared P = 0.0118). EC was the only region in which the stricter population-shift test for the state-by-phase interaction did not survive FDR correction (q = 0.052), whereas ACC (q = 0.00357), medial OFC (q = 0.000305), PCC (q = 0.000210), parahippocampal cortex (q = 0.0124), anterior hippocampus (q = 1.69 x 10^-7) and mid-hippocampus (q = 3.52 x 10^-10) all did. The derived "phasic-only" fraction, where state coding was present but collapsed in at least one phase, was also lowest and not above chance in EC (3 of 28 cells, 10.7%, binomial P = 0.163), but was above chance in ACC (25 of 159, 15.7%, P = 4.01 x 10^-7), medial OFC (16 of 167, 9.6%, P = 0.00995), PCC (15 of 64, 23.4%, P = 4.69 x 10^-7), parahippocampal cortex (7 of 61, 11.5%, P = 0.0321), anterior hippocampus (46 of 296, 15.5%, P = 1.15 x 10^-11) and mid-hippocampus (38 of 180, 21.1%, P = 4.40 x 10^-14). Thus, EC did not simply contain more state-responsive cells; rather, it showed the clearest tendency toward state coding that was not detectably driven by phase.

A complementary population RSA reached the same broad conclusion that abstract task state was represented across the prefrontal-medial-temporal recording set. In the cross-run z-scored state RSA, the state regressor was positive in every analysed region and survived BH-FDR correction across the seven ROIs: mid-hippocampus (beta = 0.0982, t = 6.62, P_perm = 0.001996, q = 0.00349; n = 88 neurons), medial OFC (beta = 0.0828, t = 5.53, P_perm = 0.001996, q = 0.00349; n = 90), ACC (beta = 0.0732, t = 4.94, P_perm = 0.001996, q = 0.00349; n = 68), anterior hippocampus (beta = 0.0707, t = 4.73, P_perm = 0.001996, q = 0.00349; n = 179), PCC (beta = 0.0465, t = 3.11, P_perm = 0.00599, q = 0.00838; n = 54), parahippocampal cortex (beta = 0.0372, t = 2.49, P_perm = 0.01996, q = 0.0233; n = 46) and EC (beta = 0.0310, t = 2.06, P_perm = 0.0419, q = 0.0419; n = 11). The EC RSA estimate should be interpreted cautiously because only 11 EC neurons entered this ROI-level population analysis, whereas the single-neuron state analysis included 28 EC cells. Nevertheless, the RSA and single-neuron analyses agree that abstract state information is distributed across the recorded network.

Finally, fMRI provided whole-brain anatomical support for the abstract state code. The state contrast survived voxel-wise family-wise error correction within an a priori prefrontal-medial-temporal search volume in left EC (peak MNI [-20, 2, -36], peak t = 5.18, P_FWE = 0.0394; n = 32 participants). When beta values were averaged within the left EC mask, the effect was positive (mean beta = 0.000801, t(31) = 2.16, one-sided P = 0.0195). A second a priori region, vmPFC, showed a positive ROI-mean effect (mean beta = 0.00182, t(31) = 2.51, one-sided P = 0.00868), although it did not survive voxel-wise FWE correction as a whole-brain discovery. A right FFA control sphere did not show a positive state effect (mean beta = -0.00249, t(31) = -2.83; directional test n.s.). Thus, the fMRI results converge with the single-neuron data in identifying EC, and more weakly vmPFC, as regions carrying abstract task-state information.

Together, these results support a factorised representation of the task. Hippocampal and parahippocampal populations encoded where the participant was in the physical environment, while EC and vmPFC carried an abstract code for where the participant was in the task sequence. The cell-level results refine this picture: state information was widespread across the recorded network, but EC was the region least detectably dominated by phase-dependent state coding. ACC showed a different profile, carrying a strong abstract-state signal together with near-future spatial tuning, consistent with a role in prospective action planning rather than in representing current physical location.
